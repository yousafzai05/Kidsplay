# 📖 About

**3D Kids Learning Playground** is an engaging educational web application built to help children learn through interactive games, animations, sounds, and rewards.

The project combines modern frontend technologies with gamification to create an enjoyable learning experience covering alphabets, numbers, science, logic, creativity, and more.

# 🚀 Installation

```bash
git clone https://github.com/yousafzai05/3D-Kids-Learning-Playground.git

cd 3D-Kids-Learning-Playground
```

Open **index.html** in your browser or run the project using **VS Code Live Server**.
